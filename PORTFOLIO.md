# Useme Portfolio Notes - M5Stick IR Remote

## Short Portfolio Description

C++ / ESP32 project for M5StickC Plus 2. The device can record IR remote signals, save them in memory, replay them, use presets, show a menu on the built-in display, and store settings across restarts.

## What To Show On Useme

- Photo of the physical device.
- Menu screen on the M5Stick display.
- Signal recording/sending screen.
- PlatformIO project view or `src/main.cpp` code fragment.

## Client-Facing Angle

This project shows that I can work beyond web and bots: embedded C++, hardware input/output, persistent memory, small-device UI, and PlatformIO tooling.
